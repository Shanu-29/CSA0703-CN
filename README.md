# CSA0703-CN
This is a small project where I took Wi-Fi scan data from NetSpot Inspector and converted it into a proper Excel file instead of leaving it stuck inside the app. NetSpot shows you stuff like SSID, BSSID, channel, frequency, signal strength, and security type for nearby networks, but there's no easy way to share it or compare scans over time from within the app itself. So I pulled that data out and organized it into a spreadsheet with each scan on its own sheet, headers frozen, filters turned on, and any networks that were flagged or selected in the original scan highlighted so they stand out. It's useful for things like Wi-Fi site surveys, troubleshooting network issues, or just keeping a clean record of what's around instead of a screenshot that nobody else can really do anything with.
